Aviso de privacidad

1. Quién trata tus datos

ITACR es un sistema web instalable (PWA) con el que el restaurante toma, prepara y da seguimiento a los pedidos. Este aviso explica cómo trata el sistema los datos de las personas que piden una cuenta de acceso. ITACR no tiene domicilio, sitio web ni correo propios: cualquier solicitud sobre tus datos se hace con el gerente, desde el mismo sistema.

2. Datos que recaba

  • Identificación y contacto: nombre completo, correo o usuario y teléfono.
  • Acceso: el rol que solicitas y tu PIN de 4 dígitos, que se guarda cifrado y nadie puede verlo.
  • Constancia: la fecha y hora en que aceptas este aviso.
  • Notificaciones: si las activas, el identificador de tu dispositivo, solo para enviarte avisos del sistema.

ITACR no recaba datos personales sensibles ni datos de pago o fiscales de las personas que usan el sistema.

3. Para qué se usan

Finalidades necesarias:

  • Crear y administrar tu cuenta de acceso.
  • Permitir que el gerente revise y apruebe o rechace tu solicitud.
  • Identificarte al iniciar sesión y darte las funciones de tu rol.
  • Enviarte avisos sobre tu solicitud y sobre los pedidos, si activas las notificaciones.

ITACR no usa tus datos para publicidad ni para otras finalidades distintas de las anteriores.

4. Con quién se comparten

Tus datos los ve el gerente para aprobar tu solicitud y administrar tu cuenta. No se venden ni se ceden a terceros. Solo los trata el proveedor que aloja el sistema y su base de datos, bajo contrato de confidencialidad, para que el sistema funcione.

5. Tus derechos

Puedes pedir al gerente que te diga qué datos tiene de ti (acceso), que los corrija (rectificación), que los elimine (cancelación) o que deje de usarlos para una finalidad (oposición). También puedes retirar tu consentimiento. El gerente atenderá tu solicitud en un máximo de 20 días hábiles. Si tus datos se eliminan, tu cuenta deja de funcionar.

6. Almacenamiento en tu dispositivo

Para mantener tu sesión y que la aplicación funcione sin conexión, el sistema guarda información técnica en tu dispositivo. No se usa para seguirte ni para publicidad. Puedes borrarla desde la configuración de tu navegador.

7. Cambios a este aviso

Si este aviso cambia, el nuevo texto se mostrará en esta pantalla. Última actualización: noviembre de 2026.
